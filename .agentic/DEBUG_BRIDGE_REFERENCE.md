# TiXL Debug Bridge command reference

Generated from `Tools/DebugBridgeCatalog/Catalog/*.json`. Do not edit this file directly.

Catalog format: 1.0. Bridge protocol version: 1. This describes JSON lines over local TCP, not HTTP or OpenAPI.

Command names are checked against source dispatch; verification IDs resolve to test methods. These checks do not prove that every behavior or target passed. See the [coverage and evidence ledger](../Tests/Editor.IntegrationTests/DebugBridgeCoverage.md) for pending cases, known limitations and runner prerequisites.

Use [getVersion](#getversion) to identify the running bridge, [getContext](#getcontext) for the active project/selection, and [getGraphState](#getgraphstate) for a known composition. No live `describe` command or operator index is added. See the [protocol guide](DEBUG_PROTOCOL.md) for transport, evaluation and safe client usage, or load the [machine-readable catalog](debug-bridge/catalog.json) in external tooling.

## addOp

Add a child operator by symbol GUID or exact case-insensitive name.

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

| Argument | Wire type | Required | Meaning | Omission / default |
| --- | --- | --- | --- | --- |
| compositionId | GUID string | No | Address a loaded composition symbol, not an instance path. | Use the focused composition. |
| symbolId | GUID string | No | A parseable ID takes precedence. Unknown GUID currently can report success without adding a child. | Resolve symbolName. |
| symbolName | string | No | Exact case-insensitive search across loaded packages. Ambiguous names report candidates. | MISSING_PARAM when no selector provided. |
| posX | number | No | Canvas X coordinate. | With neither coordinate, place on a free row; otherwise missing X is 0. |
| posY | number | No | Canvas Y coordinate. | With neither coordinate, place on a free row; otherwise missing Y is 0. |

**Result:** Object with childId and symbolId. Verify graph postcondition for unknown GUIDs.

**Errors:** NO_COMPOSITION, NOT_FOUND, AMBIGUOUS, MISSING_PARAM. Conversion/evaluation exceptions can also produce INTERNAL_ERROR; malformed envelopes have transport-level behavior.

**Effects:** Undoable graph mutation; may instantiate an operator with device/asset costs and autosave changes.

**Completion:** Immediate, including operator creation cost.

## getOutput

Inspect a focused child output or the project root, optionally forcing evaluation.

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

| Argument | Wire type | Required | Meaning | Omission / default |
| --- | --- | --- | --- | --- |
| childId | GUID string | No | Valid GUID resolves a child of the focused composition. Unparseable text follows the root path, like omission. | Use project root. |
| outputId | GUID string | No | A parseable ID takes precedence; unresolved valid ID does not fall back. | Use outputName or first output. |
| outputName | string | No | Case-insensitive name if outputId is absent or unparseable. | Use first output. |
| update | boolean | No | Force invalidation and evaluation when true. | False; return cached value. Documented default: false |
| dumpObj | path string | No | For nonempty mesh output, attempt OBJ file export. Only meaningful for geometry. | No export. |
| readCount | integer | No | Optional CPU list or GPU buffer element count; nonpositive omits elements. | 0. Documented default: 0 |
| readOffset | integer | No | Element offset clamped to &gt;=0. Count is limited by remaining elements. | 0. Documented default: 0 |

**Result:** Object with outputId,valueType,value. Scalars float/double/int/bool/string return scalar JSON; Vector2/3/4 return arrays. Unsupported types (including Matrix4x4 and List&lt;int&gt;) and missing resources return null; valueType alone does not prove value availability. Texture summary: width,height,format,mipLevels,arraySize,bindFlags,optionFlags,disposed. Geometry summary: pointCount,faceCount,cornerCount,partCount,boundsMin,boundsMax,boundaryEdges,boundaryEdgesOnCuts,boundaryEdgeSamples,nonManifoldEdges,volume,attributes. Buffer summary: sizeInBytes,stride,elementCount,disposed. Structured-list summary: type,elementCount,elementSizeInBytes. Positive buffer/list readCount adds elements when storage is available; offsets clamp to zero and out-of-range offsets produce an empty array. A 64-byte stride is interpreted as Point fields (index,position,f1,orientation,color,scale,f2), other strides as float arrays regardless of actual element type. Integer buffer bytes are reinterpreted, not numerically converted. Geometry OBJ export preserves polygon corners and writes synchronously; file errors become INTERNAL_ERROR.

**Errors:** NOT_FOUND, INTERNAL_ERROR. Conversion/evaluation exceptions can also produce INTERNAL_ERROR; malformed envelopes have transport-level behavior.

**Effects:** update can evaluate CPU/GPU code and may double-evaluate a viewed operator. GPU reads synchronously wait for readback; CPU list reads serialize the full list before slicing. dumpObj writes files. No compositionId parameter.

**Completion:** Immediate except synchronous evaluation/readback/export cost.

## getRenderStatus

Read current export state and progress.

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

No command-specific arguments.

**Result:** Object {state:string,isExporting:boolean,progress:number,frameIndex:integer,message:string}. Current state names: Undefined, NoOutputWindow, NoValidOutputType, NoValidOutputTexture, ReadyForExport, Exporting. frameIndex belongs to the active session and becomes zero after cleanup; progress can reset to zero. Existing continuous exports can report negative progress. message is human-readable status, not a structured success code.

## setGraphView

Set or adjust the focused graph canvas.

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

| Argument | Wire type | Required | Meaning | Omission / default |
| --- | --- | --- | --- | --- |
| area | object {minX,minY,maxX,maxY} | No | If an object, takes precedence over all center/scale/relative fields. Missing components are zero; max must exceed min on both axes. | Use center/scale/relative branch. |
| centerX | number | No | Absolute canvas center X before relative scrolling. | Preserve current target center X. |
| centerY | number | No | Absolute canvas center Y before relative scrolling. | Preserve current target center Y. |
| scale | number | No | Absolute scale before zoomBy. Resulting scale must be greater than 0.001 and at most 100; NaN is rejected. Center/scroll finiteness has no corresponding explicit check. | Current target X scale. |
| zoomBy | number | No | Multiply the selected scale. | One. Documented default: 1 |
| scrollByX | number | No | Add to selected center X in canvas units. | Zero. Documented default: 0 |

**Effects:** Changes graph view only. Area fitting is queued until the canvas knows its current window size.

## setInput

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

| --- | --- | --- | --- | --- |
| compositionId | GUID string | No | Address a loaded composition symbol, not an instance path. | Use the focused composition. |
| childId | GUID string | Yes | Child instance ID within the addressed composition. | NOT_FOUND. |
| inputId | GUID string | No | A parseable ID takes precedence over inputName even if it does not resolve. | Use inputName. |

## startRender

Start a video export from the current output texture.

Targets: windows-d3d11, windows-vulkan, linux-vulkan, macos-vulkan.

| Argument | Wire type | Required | Meaning | Omission / default |
| --- | --- | --- | --- | --- |
| path | string | Yes | Target path must satisfy platform Path.IsPathRooted. On Windows this is broader than fully qualified; supply a full owned path. Export setup can create the parent directory. | BAD_PATH. |
| startSecs | number | No | Requested start time in seconds. Copied into cloned render settings with seconds as their reference. | Zero. Documented default: 0 |
| durationSecs | number | Yes | Duration in seconds; values &lt;=0 are rejected. The handler has no separate finite-number validation. | Zero gives BAD_DURATION. |
| fps | number | No | Frame rate; no explicit handler range/finite validation. Advertised frameCount rounds duration times fps. | 60. Documented default: 60 |
| codec | string | No | Case-insensitive VideoExportCodec name: H264, ProRes, VP9, AV1, FFV1, Hap, HapAlpha, HapQ, Hevc. An unparseable string leaves the cloned codec unchanged; numeric strings are accepted by Enum.TryParse without defined-value checking. | Keep cloned render-settings codec. |
| exportAudio | boolean | No | Whether to include composition audio. Requires corresponding exporter/audio prerequisites. | True. Documented default: true |

**Result:** Object {path:string,frameCount:integer} acknowledges accepted settings. It does not establish encoder availability, successful completion or file readability.

**Errors:** BAD_PATH, BAD_DURATION, RENDER_NOT_READY. Conversion/evaluation exceptions can also produce INTERNAL_ERROR; malformed envelopes have transport-level behavior.

**Effects:** Clones render settings, requests video export and advances playback frame-by-frame. Requires a valid Texture2D, visible output and ReadyForExport state. Encoder setup can fail later. An existing target may be overwritten; cancellation may leave a partial file.

**Completion:** Accepted export completes over later frames. Poll getRenderStatus and inspect the actual artifact and logs; do not treat the acknowledgement as completion.

**Verification references** (execution status is recorded separately):

- Editor.IntegrationTests.CaptureContractTests.Render_ValidatesPathDurationAndReadiness
- Editor.IntegrationTests.CaptureContractTests.Render_CompletionAndCancellationHaveSeparateEvidence
- Editor.IntegrationTests.CaptureContractTests.Render_AcceptedRequestCanFailLaterWithoutAFile

**Examples and additional metadata:**

```json
{
```
